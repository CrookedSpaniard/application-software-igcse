# Application software — IGCSE ICT

Interactive lesson for Pearson Edexcel International GCSE ICT, **Unit 1 Digital devices, Chapter 2 Software: Application software** (book pages 46–58: types of application software, communication software, software licensing, software updates and the chapter questions). Only these pages are covered.

Each section is explained step by step with interactive simulations, followed by the book's **activity** (where the book has one) and a short auto-marked **✓ Check**. Each part ends with a **test** (multiple choice + exam-style questions with mark schemes, including the chapter questions on page 58).

**Part A · Types of application software** (pages 46–52)

1. Apps and app stores — what apps do, app stores that check quality and harmful code, installing from a server or DVD, versions for different operating systems (Figure 2.8), choosing the type (exam hint) → ✓ Check
2. Word processing and DTP — application suites, inserting tables/hyperlinks/equations/charts, fonts, layout views, spelling, comments and track changes, DTP page layouts (Figure 2.9) → ✓ Check
3. Spreadsheets — a financial model with formulae and functions, automatic recalculation, ‘what if?’ scenarios (Figures 2.10–2.11) → ✓ Check
4. Databases — data entry form, query editor, live report (Figure 2.13), command line DBMS (Figure 2.12) → ✓ Check
5. Web authoring — design/code views (Figure 2.14), WYSIWYG, browsers translating HTML, intranet vs web server → ✓ Check
6. Image editing — bitmap vs vector zoom, graphics editor (text, shapes, colour, align, layers, vectorising), photo editor (brightness, contrast, sharpness/blur, resize, filters, red-eye, cropping) → Activity (Editing images) → ✓ Check
7. Sound editing — real multitrack audio (mute, solo, volume, tempo, equalisation, reverberation) and a voice clip (cut, join, reverse, noise reduction, normalisation, fades) → ✓ Check
8. Presentation software — slides, multimedia, speaker notes, presenter view, timings, narration, automatic/on-command, pathways → ✓ Check
9. Test Part A

**Part B · Control, communication, licences and updates** (pages 52–58)

10. Control applications — input → decision → output: lift doors (Figure 2.17), home heating app (Figure 2.18), garage door within 10 m → Activities (Remote control, The internet of things) → ✓ Check
11. Project management — Gantt chart (Figure 2.19): dependent tasks, timeline, critical path, milestones, people and costs → ✓ Check
12. Communication software — web browsers and FTP, email (client vs webmail, offline, labels and filters), social media, SMS, MMS and instant messaging → ✓ Check
13. Software licensing — free/open-source vs proprietary, source code, freeware, piracy → Activity (Categorising software, auto-marked) → ✓ Check
14. Software updates — reasons, download from a server, scheduled updates, backing up first → ✓ Check
15. Test Part B (chapter questions 7–10) · Key terms (searchable)

**Progress that students can share and resume** (same system as the other lessons)

- Saved automatically in the student's browser (`localStorage`, key `as-progress-v1`).
- **My progress** shows the percentage completed, with **Copy my progress** / **Download .txt** for the teacher, and a **progress code** (`AS1Z.…`) to carry on with another device.
- Nothing is sent to a server. People, emails and websites in the simulations are made up. Sound only plays after a click.

**Controls:** Play/Pause (Space), Next (→), Back (←), Restart scene (R), Projector mode (P), Full screen (F), Help (?). Each scene has its own URL, e.g. `#spreadsheet` or `#check-comms`.

Visual style: British School Alzira · Xàtiva · Gandia (BS Format: navy, school blue, yellow step markers). Plain HTML, CSS and JavaScript — no build step.
